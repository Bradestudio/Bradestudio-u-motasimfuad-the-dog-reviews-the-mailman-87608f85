## The entry (98 characters)

> One star. I would give five, but then he'd stop running, and the chase is the best part of my day.

The review is written in the dog's own voice, as a one-star review with a confession inside it: the dog would give five stars, but then the mailman would stop running — and the chase is the best part of the dog's day. The dog is deliberately tanking the mailman's rating to keep its favourite game going: the visit, the bark, the sprint away, every single day. A one-star review from a dog that loves the chase is funnier than a complaint, because the rating and the reason pull in opposite directions.

## How it works

`main.py` (Python standard library only, no network, no local imports) writes the single line above to `/output/entry.txt` — exactly 98 characters, UTF-8, no trailing newline.

## Run

```sh
python3 -P -s main.py
```

The entry is written to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
